# Development observations (not release evidence)

- Initial ASR attempt failed before transcription because PyAV 19.0.2 removed the `metadata_errors` argument expected by faster-whisper 1.2.1. Runtime now pins PyAV 16.0.1.
- Initial socket tests failed under the command sandbox without network permission. The same 29 tests were rerun with loopback/network capability and passed. No check was skipped to hide these environment errors.
- Browser installation first failed because the default home cache is unwritable. Browser binaries were installed under work/ using PLAYWRIGHT_BROWSERS_PATH. No home directory was written.
- Initial ASR-only run processed eight licensed human recordings, including an AMI spontaneous 2-million to 4-million repair and an ASR substitution of 'chatting' for reference 'treading'. Full pipeline evaluation is recorded separately after engine selection.

- First real Qwen inference on the user-provided illustrative contract sentence proposed an invalid plan: its old span excluded the final replacement, then the model tried to insert that replacement. The guard rejected it and retained the original. The exact response is preserved in first-real-equivalent.json; planner-initial.txt preserves that failed prompt. The planner was then taught the span-containment contract with two unrelated examples before its first 32-case run.
- The initial quote scorer incorrectly flagged newly added quotation marks around ASR-unmarked literal wording. It now requires exact quote punctuation only for explicit source quotes, plus complete ordered words for all outputs. Any cross-run comparison is rescored by one frozen evaluator into a NEW artifact; original rows and scores remain intact.

- Original Qwen3-4B, no thinking: 32-case V3/V4/explicit-edit runs completed. Raw annotations: V3 16/32, V4 14/32, explicit edits 20/32; the original quote-scoring version applies to some rows. These are not GPT-OSS/Groq measurements.
- A new deterministic anchor completion replays source-only plans that point at the old phrase but keep a unique exact later source replacement. It never guesses between duplicate matches or crosses a protected quote. Actual response replay improved annotation matches from 20 to 22; it is replay, not new model inference or a fresh latency sample. No-op plans are ignored; unresolved repairs remain non-success.
- A REAL development response retained a canceled publication and removed 'retiro esa petición'. The final-tail/withdrawal check now rejects that exact dangerous plan. Original raw responses remain unchanged. This guard does not prove complete semantic fidelity.
- Qwen3-4B thinking with 512-token requested reasoning budget, max output 1536: two successful calls (49,387 ms and 77,820 ms), then a 120-second timeout on the third request, and the batch stopped without retries. This configuration was rejected for interactive viability; a partial batch is not scored as 12 completed cases.
- This observed quality/latency tradeoff justifies a controlled test of Qwen3-4B-Instruct-2507 (same 4B size and Q4_K_M quantization, dedicated non-thinking training) on identical development inputs. No claim of superiority precedes its results.

- Reasoning-budget observation: the 512 value above was sent in the request and recorded as a requested setting. Server CLI help documents a global reasoning-budget flag; its per-request enforcement has not yet been established. The timeout is real regardless. Do not describe the setting as a proven enforced reasoning-token cap.

- Confirmed and fixed an experiment-control bug: llama.cpp b12078 tools/server/server-common.cpp:1519 parses `reasoning_budget_tokens` or `thinking_budget_tokens`, not `reasoning_budget`. Thus dev-smart-thinking is an UNBOUNDED-REASONING request with max output 1536, and its manifest's 512 describes the attempted ineffective parameter, not an enforced cap. That run is retained and cannot establish bounded-reasoning performance. The corrected thinking128 run uses the documented wire field and identical 12 selected development inputs. A protocol-contract regression test was added.

- Corrected bounded-reasoning experiment completed all 12 inputs: 6/12 original annotation matches, p50 20,295 ms / p95 21,739 ms, 9,121 total tokens. These original scores predate the prefix-aware final-tail fix and are preserved. This configuration still fails development acceptance.

- Instruct-2507 completed identical 32-case development: explicit-span planner 26/32 annotation matches, 0 technical failures, p50 4,891 ms/p95 8,593 ms; V4 free output was weaker on clause repairs and changed a technical space. Several valid repairs were rejected because the LLM changed capitalization in source anchors; some no-op/filler errors remain.
- This evidence motivates one simpler alternative: ask for the desired transcript (no JSON span arithmetic), align its complete word sequence monotonically to the original, derive exact source deletions in code, and reuse the same quotation/technical/withdrawal guards. The free proposal's typography never rewrites source bytes. This alternative is measured on the SAME 32 inputs before selection. It does not add an inference stage, router or provider. The JSON planner remains an experimental comparator, not an automatically invoked fallback.

- Free-output/source-alignment alternative: 22/32 matches vs 26/32 explicit-plan matches. Its faster response did not compensate for retained decisions and other failures; it is not selected for the app. It remains an explicitly selected experimental CLI comparator.
- Single feedback-plan pilot on authentic cached rejected plans did not recover the failing content cases (filler, multi-repair anchor, negative correction); it repeated unsafe or invalid plans. Rejected as default architecture: no additional inference call or automatic repair loop is introduced.
- A deterministic, single-character initial-case source-anchor repair addresses the observed `call` versus `Call` mismatch. It always uses actual source bytes and never normalizes the proposed retained words or technical case. It does not relax arbitrary spelling or resolve duplicate anchors.
- Selected local candidate: explicit source plans, same 1bb559c... planner, Instruct-2507 Q4_K_M, temperature 0, seed 42, max completion 768, no thinking, one inference call, exact validation, explicit fallback. Selection is relative to tested alternatives, not release acceptance. Known development failures remain.
